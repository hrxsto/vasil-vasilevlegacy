# vasil.vasilevlegacy.net

Landing page pública de Vasil Vasilev, Consultor Independiente de Immunotec
(España) y socio de Hristo Vasilev. Publicada en <https://vasil.vasilevlegacy.net>
vía GitHub Pages (pendiente de configurar).

## Estructura

- `index.html` — la página completa: trilingüe (ES/EN/BG), sin JavaScript, sin trackers.
- `perfil-vasil.jpg`, `immunocal-box.jpg`, `science-glutathione.jpg`, `dr-gutman.jpg`,
  `favicon.png`, `apple-touch-icon.png` — recursos.
- `CNAME` — subdominio conectado a este repo.

## Cómo actualizar

1. Edita `index.html`. Cada texto existe en tres idiomas (clases `l-es`, `l-en`, `l-bg`);
   cualquier edición de contenido se hace en los tres idiomas a la vez.
2. Commit y push a `main` → GitHub Pages publica automáticamente (1-2 minutos).

## Reglas de contenido

- Sin promesas de ingresos ni de salud. Los avisos legales del pie son obligatorios.
- og:url, og:image y canonical apuntan a `https://vasil.vasilevlegacy.net/`.
- Este repo es público a propósito: contiene la foto y el WhatsApp de contacto de Vasil.
- Pendiente: favicon personalizado.
